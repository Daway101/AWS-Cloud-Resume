Hello! I’m Dawa Tsering, a ServiceNow Developer and AI Agentic Engineer who builds intelligent systems that automate, reason, and scale. I design and deploy AI-driven workflows in ServiceNow using AI Agent Studio, App Engine Studio, and Flow Designer, integrating them with AWS services, REST APIs, and n8n to create adaptive, event-driven processes. I’ve built scoped applications that handle incident triage, virtual machine provisioning, and logistics operations, applying Business Rules, ACLs, and custom tables that follow CSA/CAD best practices for scalability, governance, and clean architecture.

I have hands-on experience with core AWS services like EC2 for compute, S3 for storage, RDS for database management and the AWS Well-Architected Framework for designing scalable and secure cloud environments. I’ve gained practical insights into monitoring and troubleshooting using CloudWatch, delivering cost-effective solutions using AWS Cost Explorer and billing optimization strategies and applying IAM best practices for secure access management. My hands-on work in EC2 monitoring and remediation systems has deepened my understanding of cross-platform integration between ServiceNow and AWS.

My Himalayan roots have instilled a mindset of resilience, adaptability, and continuous improvement—values that mirror the principles of CI/CD I apply in both engineering and life.
